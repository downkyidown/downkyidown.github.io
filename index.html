哔哩下载姬是什么

把 B 站视频保存成通用 mp4 文件的桌面工具。

哔哩下载姬（DownKyi）可以下载几乎所有 B 站视频，并输出为 mp4。下载由 Aria 多线程完成，混流、提取音视频等操作由 FFmpeg 处理。官方定位是“视频解析”工具：本身不提供任何资源上传或存储，只解析来自 B 站的内容，并且不会对音视频做二次编码，部分视频仅会进行有限的格式转换和拼接。

原版面向 Windows，另有社区基于 AvaloniaUI 制作的跨平台版 downkyicore，让 macOS 和 Linux 用户也能使用。

常见问题

哔哩下载姬免费吗？

免费且开源，基于 GPL-3.0 协议，仅供学习交流使用。

Mac 或 Linux 能用吗？

原版是 Windows 程序。Mac 和 Linux 请使用基于 AvaloniaUI 的跨平台版 downkyicore，它自带运行环境，无需另外安装。

Aria 下载失败怎么办？

检查 aria2c.exe 是否能正常运行、是否被防火墙拦截，也可以尝试切换端口号。内建下载器失败时，可到官方仓库反馈。

下载时卡在“混流中”怎么办？

检查 ffmpeg.exe 是否能正常工作，被杀毒软件误删或拦截时需要恢复。

去水印怎么设置？

宽、高为水印的尺寸，X、Y 为水印在图像中的位置（以左上角为原点），这四个数值可以通过 Photoshop 等图像工具获得。

需要 32 位还是 64 位文件？

官方压缩包内的 aria2c.exe 和 ffmpeg.exe 为 32 位，需要 64 位时请自行替换为对应版本的文件。
